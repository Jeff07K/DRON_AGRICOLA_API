🎯 Barril — Disparo único

Selecciona cualquier disparo. Los valores se normalizan frente al máximo histórico de cada eje.

⚖️ Barril — Comparar 2 disparos

Elige dos disparos distintos para comparar su firma de aceleración/giro.

📊 Barril — Intensidad media global

Promedio absoluto de todos los disparos válidos por eje. Muestra el comportamiento típico del sistema.

📊 Media de los 3 ejes (g)

Línea roja = 1g (gravedad). Accel Z ≈ 1g en reposo plano.

📈 Dispersión Accel X vs Accel Y

Cada punto = media de un disparo. Muestra relación entre inclinaciones lateral y frontal.

📊 Histograma Accel Z — bins reales

Verde = zona saludable (≈1g). Rango real medido: −0.7 a 1.4 g.

📉 Accel Z por disparo — evolución temporal

Media de Accel Z en cada disparo. Útil para detectar cambios de carga o inclinación prolongada.

🌀 Media de los 3 ejes (°/s)

Barras negativas = rotación opuesta al eje. Hover muestra desviación estándar.

📊 Histograma Gyro X — bins reales (−100 a +100°/s)

Rojo = pitch negativo, ámbar = positivo. Ayuda a ver vibraciones.

📊 Varianza por eje giroscópico (°/s)²

Mayor varianza = mayor inestabilidad/vibración en ese eje.

📈 Gyro X, Y, Z — evolución por disparo

Media de cada eje giroscópico a lo largo del tiempo.

📋 Estadística descriptiva completa — n registros válidos

Media, varianza, Q1, mediana, Q3, IQR, coeficiente de variación. Calculado en tiempo real.
